# Image assets

Use this directory for approved, project-owned or licensed image files. Current homepage images are referenced through `src/data/referenceAssets.js` from the supplied `puppy.instabizweb.com` host because the runtime could not fetch binaries into this workspace. The references are documented in `ASSET_SOURCES.md` at the frontend root. Move the confirmed assets here or to an agreed CDN once usage rights and the final asset bundle are confirmed.
